# Usability correction plan

Audience: an analyst comparing ONyc and the two selected September PT positions. Primary job: establish what is unresolved, whether the scope applies, and inspect the evidence or exit condition behind the conclusion.

Reading order: exact position → NO_RATE and plain-English rationale → visible scope → three prioritized risks including underlying uncertainty → full risk disclosure → dependency structure → exit path and evidence.

Reuse the existing Kurtosis typography, status labels, source links, disclosures, tabs and restrained surfaces. Split comparison, dependencies and source observations into focused components. Mobile dependencies reveal detail next to the selection; mobile comparisons repeat field and position labels rather than requiring horizontal recall. Desktop keeps structured tables and a side-by-side layer inspector.

Navigation will reveal and focus the requested destination; browser Back/Forward will restore the previous viewport. Direct evidence and scope destinations will also work from bookmarked URLs. Keep note drafts across tabs/positions and disclose saved versus unsaved state. Source inspection will separate retained observations from analyst synthesis and link preserved records.

Evidence states, historical timestamps, limitations, missing extracts and NO_RATE remain explicit. No research values, grades or approvals will be invented. Validate the audited failures with behavioral browser checks, existing integrity/accessibility tests, production build, and desktop/tablet/mobile visual inspection.
